# Logo adjustment

Changes only the site logo and favicon.

* Keeps the same # characters, lime green color, background, frame, and corner details.
* Replaces the pointy, widening top with a short, squared cap and straight vertical sides.
* Removes the extra protruding hashes from the side edges.
* Computes the character coordinates from a centered grid, so the A is no longer shifted left.
* No other site sections, links, videos, portraits, galleries, or animations were changed.

To apply: extract the update ZIP in the root of your existing repository, run npm test and npm run build, and then commit and push to main.
